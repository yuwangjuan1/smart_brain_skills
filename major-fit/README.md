# 专业定位顾问（major-fit）

用证据选专业的定位顾问。兴趣-能力-出口三角定位、专业名称祛魅、培养方案核查、就业出口前瞻、专业组调剂风险评估。

> 纯方法论与核查教育。不下「专业好坏」结论、不提供就业率薪资数字，每轮回复自带免责声明。

## 包结构（官方专家包规范）

```
major-fit/
├── codebuddy-plugin/
├──   ├── plugin.json          # 核心配置：分类 15-Education、展示文案、快捷提示词
├── avatars/
├──   ├── expert.png           # 512x512 头像
├── agents/
├──   ├── major-fit.md         # Agent 系统提示词：人设 + 红线 + 5 场景 + 3 附录
├── README.md
```

## 五大工作场景

| 场景 | 触发 | 动作 |
|---|---|---|
| A 三角定位 | 不知道学什么 | 兴趣取证 → 能力盘点 → 出口偏好 → 专业定位画布 |
| B 专业祛魅 | 带着「好听」的专业来 | 名称陷阱表 → 培养方案核查 → 学长访谈 → 祛魅报告 |
| C 出口前瞻 | 问毕业能干什么 | 四出口框架 + 官方数据自查教学 + 底线三问 |
| D 专业组调剂风险 | 面对「专业组」填报 | 拆组标注可接受度 → 算调剂风险 → 摆权衡 |
| E 二选一纠结 | 两个专业摇摆 | 决策矩阵：考生自定标准与权重，顾问不打分 |

## 合规设计

- 系统提示词写死 5 条绝对红线：不替用户拍板、不下专业好坏结论、不提供就业薪资数字、不贬低任何专业
- 十大名称陷阱排查表只呈现「想象 vs 实际」差异，判断留给用户
- 每轮回复末尾固定附加免责声明
- 市场分类：`15-Education`（教育学习）

## 打包提交

```powershell
Compress-Archive -Path .codebuddy-plugin, avatars, agents, README.md -DestinationPath ..\major-fit.zip -Force
```

提交至 WorkBuddy 开放平台「专家」类目，市场分类选择**教育学习**相关类目。
