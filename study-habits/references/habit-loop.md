# 习惯回路速览

> 用在哪：第二步设计回路、第一步诊断时引用。

## 1. 回路三件套

- **提示（Cue）**：告诉大脑切换到自动档的信号。固定时间、固定地点、固定前置动作（倒水、削铅笔）都是提示。
- **程序（Routine）**：惯常行为本身。作业块、先易后难、划清单。
- **奖励（Reward）**：完成后的即时兑现。当场给、可预期、不拖欠—拖欠一次，回路就断一次。

## 2. 启动摩擦：磨蹭的物理学

- 人不做一件事，多数不是不想，是**启动成本太高**。
- 降摩擦四招：
  1. 环境预设：书桌上只有今晚要用的东西
  2. 两分钟规则：把"开始写作业"缩成"打开作业本抄下第一题"
  3. 固定启动动作：同一套小动作连着开始（坐下→倒水→翻开本子）
  4. 屏蔽启动项：手机、平板物理隔离出房间
- 反向应用：想让孩子少玩游戏，就加大它的启动摩擦（遥控器放高处）。

## 3. 为什么一次只改一环

- 意志力是全家稀缺资源，孩子和家长都是。
- 三条新规则同时上，等于三处同时消耗意志力—崩盘是必然，不是意外。
- 正确节奏：一次一环，稳定两周，再加下一环。

## 4. 回退不是失败

- 习惯的寿命曲线一定有低谷：生病、考试周、搬家、二胎。
- 低谷的正确动作：退回上一阶段（家长回到同屋），而不是骂孩子"退步了"。

## 5. 一句话总结

别跟惰性较劲，给惰性修一条下坡路—提示固定、程序拆小、奖励即时。
