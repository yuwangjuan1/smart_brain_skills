# 切换信号清单

> 用在哪：第一步识别，命中两条以上 = 系统1越权，吹哨。

## 内在信号（身体和嘴会说谎，先查这五个）

- [ ] **迫不及待**：想立刻拍板，等一小时都嫌久
- [ ] **说服欲过载**：急着让别人同意，而不是自己先想清楚
- [ ] **"肯定对"**：这个判断感觉特别对，对到不需要检查
- [ ] **心跳 / 呼吸变化**：兴奋、紧张、上头的体感
- [ ] **状态欠费**：深夜、疲惫、饥饿、刚吵完架

## 情境信号（事情本身的属性）

- [ ] **重大**：涉及大钱、大时间、重要关系、公开声誉
- [ ] **不可逆**：签了字、转了账、说出口就收不回
- [ ] **陌生领域**：不满足"熟悉环境 + 及时反馈"双条件
- [ ] **统计题**：需要算概率、比率、期望值，直觉最不擅长
- [ ] **被催促**：有人制造"过期不候"的紧迫感

## 回切信号（什么时候放回系统1）

- 简单重复题（通勤路线、午饭吃什么）
- 熟悉领域 + 有及时反馈（本职专业内的日常判断）
- 已通过哨声流程、复核放行的结论（别反复过夜）

## 组合判据

- 内在 2 条 + 情境 1 条 → 完整哨声流程（识别→延时→反证→推演）
- 仅情境 2 条 → 至少延时复核 + 找一个反例
- 0 条 → 放行，别把哨兵开成拖延症
