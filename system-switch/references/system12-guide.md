# 双系统理论速览

> 用在哪：第一步识别、复核讲解时读。依据卡尼曼《思考，快与慢》。

## 1. 两个系统

| | 系统1（快直觉） | 系统2（慢推理） |
|---|---|---|
| 速度 | 自动、瞬时 | 受控、费力 |
| 产能 | 24 小时在线 | 认知预算有限，易疲劳 |
| 擅长 | 熟悉模式、面部表情、简单算术 | 统计、逻辑、多步骤推演 |
| 弱点 | 会被替换问题、轻信、过度自信 | 懒，默认放行系统1的答案 |

## 2. 系统1的三板斧（它怎么骗过你）

- **替换问题**：把难问题（这个项目值得投吗）偷偷换成易问题（我喜欢这个描述吗）
- **认知放松**：重复见过的话 / 好读的文案，会让"感觉熟悉"被当成"感觉真实"
- **因果幻觉**：把随机事件编成故事，"这只股票上次也是这样起飞的"

## 3. 什么时候可以信直觉（Klein + Kahneman 共识）

两个条件同时满足才信：
1. **熟悉的环境**：规律长期稳定（ chess、消防、你的本职专业 ）
2. **及时的反馈**：做错了马上知道（有复盘机会）

不满足任意一条（股市、创业、新领域、低频重大决策），直觉不可信，走系统2。

## 4. 常见错误（哨兵要拦的）

- 把系统2复核做成给系统1结论补理由·复核必须真找反例
- 用"我很理性"的感觉本身当复核结果·感觉不是证据
- 疲惫 / 饥饿 / 赶时间时做重大判断·系统2缺电，默认放行直觉

## 5. 一句话总结

直觉负责出答案，系统2负责验票；哨兵的活儿，是在验票口拦住插队的人。
