# for循环和while循环怎么选

一句话：**遍历已知集合用 for，满足条件才停用 while。**

- 遍历列表/字符串/字典 → for
- 不知道要循环几次（如"用户输入对了才停"）→ while
- while 必须想清楚"什么条件下退出"，否则死循环

实践记录：写猜数字游戏时用了 while + break，见项目页。
```

# 错题：递归忘记写终止条件

## 场景
用递归算阶乘，一运行就爆栈 RecursionError。

## 我怎么错的
只想"函数自己调自己"，写完就跑，没检查"什么时候停"。

## 根本原因
流程缺失：懂递归原理，但写函数前没有"先定终止条件"这个固定步骤。

## 正确姿势
写任何递归，第一行先写终止条件（if n <= 1: return ...），再写递归体。

## 关联
[[什么是递归]]
```
