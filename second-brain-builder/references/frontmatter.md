# Frontmatter 元数据规范

frontmatter 是笔记头部被 `---` 包裹的 YAML 块，是第二大脑"机器可读"的关键——有了它，未来才能接上 AI 检索、自动索引、过期提醒等一切自动化。

## 基础字段（所有笔记通用）

```yaml
---
tags: [读书笔记, 心理学]     # 主题标签，2-4 个即可
created: 2026-10-13          # 创建日期
status: seedling             # 生长状态（见下文）
---
```

## status 三态模型（推荐）

不用复杂的"完成度百分比"，只用三态：

| 状态 | 含义 | 视觉记忆 |
|---|---|---|
| `seedling` 🌱 | 刚记下，想法不成熟 | 种子 |
| `budding` 🌿 | 整理过，有了结构，还缺实践检验 | 幼苗 |
| `evergreen` 🌲 | 经过实践/反复验证，可放心引用 | 常青 |

升级条件要严格：`evergreen` 必须是"用过至少一次且有效"的笔记。这个模型的价值在于**复习时一眼知道哪些可信**。

## 按笔记类型的扩展字段

### 错题卡（放在 50-复盘）

```yaml
---
tags: [错题集]
created: 2026-10-13
status: seedling
domain: 投资心理             # 属于哪个领域
error-type: 认知偏差          # 错因分类：知识缺口 / 认知偏差 / 流程缺失
recurred: 0                  # 复发次数，每错一次 +1
---
```

### 领域包内笔记（放在 20-领域）

```yaml
---
tags: [领域包, 投资心理学]
created: 2026-10-13
status: budding
domain: 投资心理学
source: ""                   # 来源（书/文章/课程），没有就留空
---
```

### 创作发布稿（放在 40-创作）

```yaml
---
tags: [创作]
created: 2026-10-13
status: seedling
platform: 公众号             # 发布平台
published: ""                # 发布日期，未发布留空
topic: "损失厌恶的 3 个日常例子"   # 一句话主题
---
```

## 索引页规范

每个目录配一个索引页，结构固定为：

```markdown
# 目录名

> 一句话说明这个目录是干嘛的。

## 导航
- [[子目录/笔记1|笔记1]] —— 一句话说明
- [[子目录/笔记2|笔记2]] —— 一句话说明

## 最近更新
<!-- 手动维护，每周整理时更新 3-5 条即可 -->
```

## 原则

1. **字段宁少勿多**——每个字段都要问"半年后我还愿意维护它吗"
2. **tags 不超过 4 个**——标签爆炸是知识库腐烂的第一症状
3. **留空好过造假**——没来源就留空，不要写"网络"
4. Obsidian 里可用属性面板（Properties）编辑 frontmatter，不用手写 YAML
