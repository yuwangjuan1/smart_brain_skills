# 错题集方法论

错题集不是学生专利，是所有学习者最被低估的资产。核心思想：**普通笔记记录"我学到了什么"，错题记录"我错在哪"——后者含金量高一个数量级**，因为每个错题都是真实发生过的思维漏洞。

## 为什么需要错题集

- 学了就忘的根本原因：输入没有经过"错误暴露"环节，知识没有挂钩
- 同一个坑反复踩：没有结构化的复盘，教训只停留在"下次注意"的模糊承诺
- 面试/复盘/写作时，错题是最好的素材库——真实的失败比抽象的道理有说服力

## 错题卡结构

一张合格的错题卡回答五个问题：

```markdown
# 错题：过度相信"专家说"

- **日期**：2026-10-13
- **场景**：（当时在做什么、面对什么决策）
- **我怎么错的**：（当时的思维路径，越具体越好）
- **根本原因**：（归类：知识缺口 / 认知偏差 / 流程缺失）
- **正确姿势**：（下次遇到同样场景，第一步做什么）

关联：[[相关概念笔记]]
```

五问中最重要的是第 4 问"根本原因"——归因到**类别**而不是具体事件，才能迁移。

## 三类错因分类法

| 类别 | 判断标准 | 解法 |
|---|---|---|
| **知识缺口** | "我不知道这个概念/事实" | 补输入：读书、查资料，纳入领域包 |
| **认知偏差** | "我知道，但当时被情绪/直觉带偏了" | 建检查清单：决策前强制过一遍 |
| **流程缺失** | "我懂，但环节上漏了/晚了" | 改流程：把该步骤写进执行清单 |

## 复盘节奏

- **记录**：发现错的那一刻就记，哪怕一句话占位，周末补全
- **周复盘**：每周翻一次本周错题，只做一件事——问"这个错因我以前犯过吗？"
  - 犯过 → `recurred` 字段 +1，**复发 ≥2 的错题升级为"红线检查项"**写进执行清单
- **季度复盘**：统计错因分布，哪类最多就重点补哪类

## 进阶：错题 → 检查清单

错题集的最终形态是**一张越来越短的检查清单**：

```markdown
# 决策前检查清单（由错题集沉淀）
- [ ] 这个结论有没有反例？我找过吗？（← 源自错题 #3）
- [ ] 我是在状态好的时候做的决定吗？（← 源自错题 #7，复发 2 次）
```

当一条错题变成了清单上的一行，它就完成了使命——从"教训"变成了"系统"。

## 使用边界

- 不用错题集记"别人的错"——只记自己的，情绪才有分量
- 不追求一次记全——粗记好过不记
- 不要用错题自责——错题卡是资产，不是悔过书
