# 决策类型与分流规则

> 用在哪：开场分流、第一步「定诊」时读。

## 1. 先分两类：可逆 vs 不可逆

| 类型 | 判断 | 处置 |
|---|---|---|
| 双向门（可逆） | 错了能退，代价小 | **快决策**：够七成信息就动手，边做边调 |
| 单向门（不可逆） | 难回头，代价大 | **慢决策**：走完五步手术，隔夜复核 |

判断可逆性的三问：

1. 做错了，退回原状的代价是？
2. 退回需要多久、还有几次机会？
3. 这个决定的后果会持续影响多久？

## 2. 再分节奏：快 vs 慢

- **快决策**（今天吃什么、买哪只杯子）：直觉 + 一条理由，别浪费系统 2。
- **慢决策**（跳槽、买房、离婚、创业、大额投入）：强制纸面推演 + 隔夜复核 + 找反方。

**核心原则**：把慢决策当快决策做，是后悔最主要的来源。

## 3. 常见决策场景与提醒

| 场景 | 典型陷阱 |
|---|---|
| 职业选择（跳槽 / 创业 / 读研） | 只算收益不算机会成本；被"别人都在"带节奏 |
| 大额消费（房 / 车 / 教育） | 沉没成本；把"想要"当"需要" |
| 关系取舍（留 / 走） | 损失厌恶；把选择看成零和 |
| 自我投资（学 / 不学） | 可得性（只看到成功者）；低估周期与投入 |
| 时间分配（做 / 不做） | 不把"什么都不做"算成一个选项 |

## 4. 决策重量分级（决定流程走多全）

| 级别 | 典型规模 | 流程 |
|---|---|---|
| L1 轻 | 一顿饭钱内 / 几分钟能改 | 直觉 -> 走 |
| L2 中 | 一顿饭到月薪 / 可退 | 选项 3 个以上 + 一条理由 -> 走 |
| L3 重 | 超过月薪 / 难退 | 走完整五步 + 隔夜复核 |
| L4 命运 | 不可逆 / 影响数年 | 五步 + 找 2 个反方 + 设复查点 |

## 5. 分流话术（内部用，不必全说给用户）

```
情绪强烈（崩溃/上头/失眠）？        -> 先降温，推迟决策
选项只有"做/不做"两个？            -> 强制扩到 3 个以上 + 什么都不做
理由里只有"过去"（成本/时间）？     -> 疑似沉没成本，切第四步验尸
紧迫感来自"别人都在做"？           -> 疑似从众，切偏差六查
问的是"该不该 X"？                 -> 先帮他找真问题（重新定义）
```
