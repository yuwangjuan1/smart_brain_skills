# 心理复盘卡

> 每完成一次情绪化操作复盘，填一张卡。卡片只记录心理过程，不记录任何具体标的名称与操作建议。

```markdown
# 心理复盘卡 · {日期}

## ① 事实层（只写发生了什么，不写感受）
- 触发事件：{看到/听到了什么}
- 我的操作：{做了什么}
- 操作时的市场状态：{上涨/下跌/横盘，波动是否剧烈}

## ② 情绪层（给情绪命名）
- 当时最强烈的情绪：{恐慌 / 兴奋 / 懊悔 / 怕踏空 / 麻木 / 其他}
- 身体信号：{心跳加速 / 睡不着 / 不停刷新行情 / 其他}
- 情绪强度（1-10）：{分数}

## ③ 决策层（信息 vs 感受）
- 我当时的理由：
  - 有事实/数据支撑的部分：{...或"无"}
  - 纯感受的部分：{"感觉要涨" / "怕再跌" / "别人都在赚" ...}
- 如果当时空仓，我还会做同样的操作吗：{会 / 不会 / 说不清，为什么}

## ④ 偏差归因（勾选最匹配的一项）
- [ ] 损失厌恶：亏损时不敢看、死扛；盈利时急着落袋
- [ ] 沉没成本：因为"已经亏了/拿了很久"而不甘心
- [ ] FOMO 追涨：因为"别人在赚/正在涨"而紧迫
- [ ] 本次不属于典型偏差，属于：{自定义}

## ⑤ 下次预案（一条可执行的纪律）
- 如果再出现同样的情境（触发事件 + 情绪信号），我将：
  {例：先离开屏幕 30 分钟，回来后写下买卖理由各三条再决定}

## ⑥ 一句话总结
- {用自己的话，说给三个月后的自己}
```

---

## 使用规则

1. **一操作一卡**：复盘对象是"一次情绪驱动的操作"，不是某只标的
2. **卡片永不出现在公开场合**：心理复盘是写给自己的，无需给任何人看
3. **每月回看一次**：统计出现最多的偏差类型，它就是你的"主力心理漏洞"
4. **预案要可执行**：写"我要冷静"无效，写"离开屏幕 30 分钟"才有效
