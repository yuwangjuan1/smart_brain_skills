# 投资原则卡

> 在情绪平稳期制定，在情绪激动时使用。每条原则必须**可执行、可验证**，拒绝空话。

```markdown
# 我的原则 · {制定日期}

## 我的投资目标（为什么投资）
- {例：让闲钱跑赢通胀，5 年内不动用}
- 我能承受的最大回撤：{数字}%，超过这个数说明我的仓位/品种配错了

## 操作纪律（事前规则，触发了就必须执行）
1. 冷静期：任何买入/卖出决定，先离开屏幕 {30} 分钟，写下理由再执行
2. 理由清单：每次操作前写出 {3} 条独立理由；写不满 3 条，视为没有理由
3. 单笔上限：单一决策投入不超过总资金的 {__}%
4. 看盘频率：非必要不看盘，每周固定 {__} 次复盘
5. 情绪熔断：心跳加速/睡不着/不停刷行情——三个信号出现任意一个，只允许看，不允许动

## 我的主力心理漏洞（从复盘卡统计得出）
- 我最容易犯的偏差：{损失厌恶 / 沉没成本 / FOMO}
- 它的典型触发情境：{...}
- 对应预案：{...}

## 每季度自检三个问题
1. 过去三个月，我有几次操作违背了上面的纪律？分别触犯了哪条？
2. 我的"主力心理漏洞"有改善吗？（对比复盘卡统计）
3. 哪条纪律形同虚设？删掉它或改成真正能执行的版本

---
签名：{写给自己的，签自己看得懂的名字}
```

---

## 使用规则

1. **平稳期制定，激动时使用**：情绪上头时打开这张卡，逐条对照
2. **原则宁少勿多**：5 条以内才背得下来，背不下来的原则等于没有
3. **数字必须填**：凡是空着 {__} 的，说明还没想清楚，不许跳过
4. **每季度修订**：原则是活的，随认知升级；但修订只能发生在情绪平稳期
