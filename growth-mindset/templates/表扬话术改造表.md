# 表扬话术改造表

> 用在哪：第四步固化。左栏是脱口而出的，右栏是改过后说出口的。

## 改造原则

夸**过程**（努力、策略、进步、选择），不夸**人**（聪明、天才）；描述你看到的，不贴标签。

## 日常改造对照

| 脱口而出（固定型） | 改造后（成长型） | 改了什么 |
|---|---|---|
| 你真聪明！ | 你刚才试了三种方法才解出来，这个不放弃的过程特别棒 | 天赋 → 过程 |
| 你真是画画的天才 | 你画了三次，每次都调整颜色搭配，越来越有想法 | 天赋 → 迭代 |
| 太棒了，全对！ | 这道题你检查出错误自己改了，这个检查习惯值钱 | 结果 → 策略 |
| 你就是比别人家孩子强 | 比上个月你自己进步了（具体指出哪里） | 比他人 → 比自己 |
| 没事，你天生不是学数学的料 | 这次方法不对，我们换个思路再试 | 判死刑 → 找方法 |
| 真乖 | 你今天自己收拾了书包，这就是负责任 | 笼统 → 具体行为 |

## 考砸时的话术（更要紧的时刻）

| 脱口而出 | 改造后 |
|---|---|
| 我早就说过你不复习吧 | 分数只告诉我们哪里没学会，不告诉我们你是谁。卷子给我看看，找到漏掉的点 |
| 你看看人家XXX | 我们只跟昨天的你比：这道题上个月你不会，现在会了 |
| 哭什么哭，考完还有脸哭 | 难受说明你在乎，在乎是好事。哭完我们一起看哪里能补 |

## 使用提醒

- 改造不是话术表演—孩子分得出真假夸奖，描述必须真实具体。
- 夸完不加"但是……"："你很努力，但是……"会让前面的努力清零。
