# 贴标签陷阱速览

> 用在哪：第二步分类时引用。

## 1. 标签怎么变成真的：自证预言

- 孩子对家长的评价照单全收，并用行为去**证实**它—被叫"磨蹭"的孩子，会越来越熟练地磨蹭。
- 机制：标签 → 孩子按标签预期自己 → 行为贴合标签 → 家长强化标签 → 标签更牢。
- 家里的"性格判词"（胆小/倔/数学不好）多数是标签，不是事实。

## 2. 高危标签清单

- **能力判死刑**："就不是学习的料""没数学脑子"—直接掐灭尝试动机。
- **性格盖棺**："胆小""自私""磨蹭大王"—行为问题一旦变成身份问题，就再也改不动。
- **家族遗传话术**："随你爸/你妈"—孩子学到：缺点是出厂设置，无需负责。

## 3. 撕标签三步

1. **行为重述**：把"他就是懒"换成"他今天作业启动花了 40 分钟"—行为可改，身份不可改。
2. **找例外证据**："上周三他十分钟就开写了，那天有什么不一样？"—例外证明标签不成立。
3. **换预测方向**："你上次自己规划了复习，这次要不要再试一次？"—预言他做得到，他就倾向做到。

## 4. 一句话总结

你怎么称呼孩子，孩子就怎么长—标签是全家最便宜的诅咒，也是最好解的。
