# 完整示例：要不要裸辞去创业

> 用户：我在大厂待了 5 年，最近特别想裸辞做独立开发，但存款只够撑一年，又开始怕。帮我理理。

**决策技能**：好，我们把它拆开。先分个类—这是一道慢决策（不可逆、影响数年），值得走完整流程。

## 第一步 · 定诊
- 可逆性：辞职再回大厂不是不行，但空窗期、职级、心态都有代价 → 偏单向门。
- 真实问题：用户问的是"要不要裸辞"，但背后可能是"我在现在的工作里看不到成长，又怕失去稳定"。
- 升维定层：这道题的分量在道（我要什么样的生活），不在术（简历怎么改）；先想清生活形态的优先级，再谈验证策略。
- 重新定义：不是"辞不辞"，而是"如何在保住安全垫的前提下，验证自己适不适合独立开发"。

## 第二步 · 拆解
1. 立刻裸辞，全职做独立开发
2. 在职做副业项目，用 3-6 个月验证
3. 内部转岗 / 换一个更想投入的团队
4. 什么都不做，先攒够 18-24 个月生活费

## 第三步 · 验尸
事前验尸，假设一年后彻底失败，可能的原因—
- 副业没起色就断了现金流
- 独处久了，失去社交与信息来源
- 项目做了半年没人用，信心崩掉

偏差六查（挑两条）：
- 沉没成本：因为"已经在大厂熬了 5 年"而不舍得走
- 可得性：只看到少数独立开发者成功的案例，忽略沉默的大多数

## 第四步 · 推演
- 10/10/10：10 分钟后会爽，10 个月后可能焦虑，10 年后可能庆幸试过。
- 二阶后果：裸辞 → 没收入 → 压力大 → 急着变现 → 做砸项目。这一串才是真正要防的。
- 可逆性对冲：先走选项 2（在职验证），等于给"不可逆"装了个刹车。

## 第五步 · 开方（决策备忘卡）
- 决策类型：不可逆慢决策，L3
- 真实问题：如何在安全垫内验证"我适不适合独立开发"
- 我的决定：选 2，在职用 3 个月做一个真实小项目，设定明确的验证指标
- 最坏情况：3 个月没做出来，代价是休息时间被占用 → 可承受
- 复查信号：项目有真实付费用户 → 考虑加大投入；3 个月毫无进展 → 回到选项 4
- 签收：这是我的决定。
