# 决策矩阵

> 选项多、维度多时用它量化权衡。分数 1-5 分，权重合计 100%。

## 用法
1. 列出所有选项（含"什么都不做"）。
2. 列出你在意的维度，给每个维度一个权重。
3. 每个选项每个维度打 1-5 分。
4. 加权求和，得总分。

注意：分数只是辅助，别被高分绑架—权重和打分本身就暴露了你的真实偏好。

## 模板
| 维度 | 权重 | 选项A | 选项B | 选项C | 什么都不做 |
|---|---|---|---|---|---|
| 收益 | 30% |  |  |  |  |
| 成本 | 20% |  |  |  |  |
| 可逆性 | 20% |  |  |  |  |
| 长期价值 | 20% |  |  |  |  |
| 情绪代价 | 10% |  |  |  |  |
| **加权总分** | 100% |  |  |  |  |

## 读表
- 哪个选项总分最高？
- 有没有某个维度你其实"一票否决"？
- 换个权重（比如把"长期价值"提到 40%），结论会变吗？会变，说明这个维度才关键。
