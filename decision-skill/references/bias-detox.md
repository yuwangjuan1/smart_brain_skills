# 偏差解毒六查

> 落定前跑一遍。每条：一句定义 + 一个自问 + 一个反制。

## 1. 锚定效应
- **定义**：第一个数字 / 信息，无端拖住你的判断
- **自问**：如果没看到那个初始数字，我还会估这么高 / 低吗？
- **反制**：先独立估值，再看别人的数

## 2. 损失厌恶
- **定义**：怕失去的痛苦，约为得到的快乐的两倍
- **自问**：我是在"争取收益"，还是在"避免确认损失"？
- **反制**：换框架—把"会失去什么"改写成"会得到什么"，再估一遍

## 3. 可得性启发
- **定义**：越容易想起的事，越被当成常见
- **自问**：我是不是只因为"最近见过 / 记得住"，才觉得它概率高？
- **反制**：去找基础数据，别拿回忆当概率

## 4. 基率忽视
- **定义**：只顾个案细节，忘了这件事的一般成功率
- **自问**：这类事通常的成功率是多少？我的特殊理由足以偏离它吗？
- **反制**：先写基础比率，再往上修正

## 5. 沉没成本
- **定义**：把已经投入的成本，算进未来的决策
- **自问**：如果今天从零开始，我还会投入吗？
- **反制**：只问"未来的收益与成本"，不问"已经花了多少"

## 6. 确认偏误
- **定义**：只找支持自己已有想法的证据
- **自问**：有没有一条能推翻我的证据？我主动找过吗？
- **反制**：强制找 3 条反方证据，或请一个人扮演反方

## 附加第 7 查 · 从众 / 社会认同
- **自问**：我做这个，是基于我的判断，还是"别人都这样"？
- **反制**：把"别人在赚 / 别人都做"从理由清单里划掉，看还剩什么
