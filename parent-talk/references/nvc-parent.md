# 非暴力沟通亲子版速览

> 用在哪：第四步议事情时引用。改编自马歇尔·卢森堡《非暴力沟通》。

## 1. 四要素（家长版）

1. **观察**：说事实，不说评判。"这周有三天作业写到 11 点"（对）；"你就知道拖"（错）。
2. **感受**：说自己的感受，不说指责。"妈妈有点着急"（对）；"你气死我了"（错）。
3. **需要**：说出感受背后的需要。"我需要知道你的进度，才不会瞎担心。"
4. **请求**：提具体可执行的请求，不是命令。"今晚我们一起把作业拆成三段，中间休息 10 分钟，试一次好吗？"

## 2. 亲子版两个特有调整

- **孩子优先于流程**：标准 NVC 是四方块连说，对孩子要先接情绪（技能四步的前三步），再上四要素—顺序：先他的感受，再你的观察感受需要请求。
- **请求不是要求**：孩子可以说不。被拒绝后不改成威胁（"你必须"），而是协商（"那你觉得怎么安排？"）。

## 3. 常见错位对照

| 家长说（错位） | 孩子听到 | 改成（对位） |
|---|---|---|
| 你怎么又这样 | 我是个错误 | 这周第二次了，我们看看卡在哪 |
| 我都是为你好 | 我的感受不重要 | 我担心你，也想听听你的想法 |
| 再这样没人喜欢你 | 爱是有条件的 | 这个行为不好，但我们依然爱你 |
| 你要是考不好就完了 | 输一次=全完 | 一次考试是一个信息，不是判决 |

## 4. 一句话总结

沟通的目标不是让孩子听话，是让话能到达孩子那里—顺序对了，话就到了。
